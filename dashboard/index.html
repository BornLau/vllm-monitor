接入你的推理服务

在服务器配置项目与节点，Key 通过环境变量提供。

  1. 复制示例并修改项目名称、节点 URL 与角色。
  2. 在 .env 填写 API Key；无需认证时删掉对应的 *_key_env 字段。
  3. 重启 dashboard，Prometheus 会自动发现新节点。
cp services.example.json services.json
cp .env.example .env
# 编辑 services.json 与 .env
docker compose up -d --build --force-recreate dashboard

独立部署：添加 engine 节点，配置 api_base_url（含 /v1）及完整 metrics_url。

PD 分离：分别添加 gateway、prefill、decode 节点；每类可以有多个实例，入口与各节点可以使用不同 Key。

API 探测只调用 /models，用于验证可达性与认证；KV、排队、吞吐需要引擎暴露 /metrics。节点延迟不代表 PD 全链路延迟，KV 传输需对应 connector 的额外指标。
