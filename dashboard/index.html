每个模型，只填三项

名称方便识别，URL 填服务地址，API Key 没有就留空。

1. 复制 .env.example 为 .env，填写两个模型
MODEL_1_NAME='GLM-5.3-Flash'
MODEL_1_URL='http://你的服务器:8080'
MODEL_1_API_KEY='你的 Key'

MODEL_2_NAME='Qwen3-32B'
MODEL_2_URL='http://你的服务器:8000'
MODEL_2_API_KEY='你的 Key'
2. 启动或更新监控
docker compose up -d --build

URL 带不带 /v1 都可以。添加第三个模型时，继续填写 MODEL_3_NAME、MODEL_3_URL、MODEL_3_API_KEY。

同一端口有 /metrics 就展示性能指标；没有时只展示 API 连通性。PD 分离先按一个入口监控，不推断背后的节点状态。Key 只在后端使用。
